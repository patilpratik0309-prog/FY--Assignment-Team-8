Library Management System
📚 Introduction
The Library Management System is a simple software project designed to manage library activities efficiently. It helps manage books, students/members, book issuing, returning, and library records.
🎯 Objectives
Manage book records.
Manage member/student details.
Issue books to members.
Return books easily.
Track available and issued books.
Maintain library records accurately.
✨ Features
Book Management
Add new books
Update book details
Delete book records
Search books
Member Management
Add member details
Update member information
Delete member records
Search members
Book Issue
Issue books to members
Record issue date
Check book availability
Book Return
Record returned books
Update book availability
Calculate fine if applicable
Search
Search books by title, author, or ID
Search members by name or ID
